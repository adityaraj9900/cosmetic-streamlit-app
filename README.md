# Cosmetic Streamlit App

A data-driven cosmetics analysis and recommendation app built with Streamlit and Python.

## Tech Stack
- Python, Streamlit, Pandas

## Features
- Cosmetic product analysis
- Ingredient comparison
- Data visualization

## Getting Started
```bash
pip install streamlit pandas
streamlit run app.py
```
